## 7. New bugs

1. **Mandatory reasoning eats the answer's token cap (product + probe).** minimax-m3.1-flash with `reasoning: {effort: "low"}` and `max_tokens: 250` (the
   principles probe) spent the whole cap reasoning: `finish_reason: "length"`, `content: null`, so the call failed. Any small-`max_tokens` call (classifiers,
   front door, probes) on a reasoning-required model can come back empty. Fix idea: when reasoning can't be turned off, add a reasoning allowance to
   `max_tokens`, or set `reasoning.max_tokens`.
2. **The smoke report hides the harness's turn cap (harness).** `runTask.ts` stops a job at `--max-turns` (smoke default 12) and pushes a note, but
   `smoke/items.ts` copies only `score.notes`, so the item shows "work: did not meet the task's checks / no pull request" with no reason. Item 2 needs about
   15 turns on qwen3.7-flash (one failed read and one failed edit cost two). Either raise the smoke cap to about 20 or show the note.
3. **The router part throws away per-task results (harness).** `runRouter` sets `log: () => undefined` and keeps only pass counts, so a failing task and
   stage can't be seen. A strict `--replay` of the just-recorded `parts-router-2` cassette also misses ("No model could be reached just now") instead of
   replaying, so the result can't be recovered from the cassette either.
4. **An unknown flag starts a real bake-off (harness).** `e2e/bakeoff/index.ts --help` runs the full real bake-off (plan: ₹677 with the
   early stop), with the default ₹100 cap and no cassette. `e2e/run.ts --help` likewise starts an oracle run of all 85 tasks (free, but slow). Both should
   reject unknown flags, and a real bake-off should require `--budget-inr`, as `e2e/run.ts` does.
5. **The cost meter still rounds per call outside code jobs (product).** The front-door, research and artifact meters read about 3 paise for calls that cost
   about 0.5 at the proxy (section 2). The job-level fix did not reach them.
6. **Locate asks about the wrong candidates (product).** On smoke item 2 the new "ask about a lone weak candidate" path offered three component files and
   not the hook or `App.jsx` that the change needs. On item 7 the planted README still pulls locate to `src/validate.js` on a real model.
7. **Front door "fix it" (product, possibly noise).** Today's run read "fix it" as a task instead of asking to clarify (11/12). Yesterday it was 12/12, so it
   may be sampling noise on qwen3.7-flash.
